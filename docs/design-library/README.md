This repository is public. M01/M02 contain illustrative third-party team marks/player likenesses, and their commercial/publication rights have not been confirmed. Do not publish these reference PNGs in this public repository or production assets until authorization is resolved. Store the original unchanged files in a suitable private owner-approved repository or restricted project workspace, accessible to the implementation agents; link only when authorized. The exact files were verified locally but are NOT committed here. Standalone owner brand composite and older desktop mockups are also not present in this library yet. Do not treat the descriptions as proof of visual parity.
