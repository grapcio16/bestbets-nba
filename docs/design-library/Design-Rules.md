# Mandatory design and implementation rules
Both automations, Codex and designers should consult this library and PR #212 before UI work. Check current HEAD/main and branch overlap; separate technical and visual branches. Use actual reference image at agreed viewport; screenshot before/after (1231x691, 1672x941, 390x844, 430px width, 844x390); document differences in layout, typography, spacing, color, iconography, charts and interaction. Mockups with device frames are visual direction, not pixel measurement at device scale. Never claim 1:1 parity when source absent. If reference missing, do independent work or create labelled prototype; request precise source only when blocked. No unapproved redesign, no changing test assertions merely for green CI, no fictitious data, no licensed assets in production without rights, no production writes, no merges or deployment without release approval. Keep mobile and desktop regression, premium/account and admin checks, and data accuracy. Report actual changed files, SHA, test evidence and outstanding differences. Owner approval is separate from CI. A new target does not automatically replace a previously approved screen.
